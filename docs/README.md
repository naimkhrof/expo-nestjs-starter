# Documentation de votre application

Le template fournit le socle technique ; les besoins produit appartiennent à chaque application.

Placez ici votre PRD, backlog, spécifications, parcours, modèle de données, design system et décisions d’architecture selon les besoins. Les changements détaillés peuvent vivre dans `openspec/` et référencer ces documents.

Les sources des starters et des guides sont conservées dans [THIRD_PARTY.md](../THIRD_PARTY.md) et `.agents/skills.lock.json`. Aucun document produit ni donnée de Dhikr n’est distribué dans ce template.
