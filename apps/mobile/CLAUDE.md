# Mobile Obytes / Expo

Étendre le socle présent : `src/global.css` pour les tokens Uniwind/Tailwind, `src/components/ui` pour les primitives, `src/app` pour les routes Expo Router. Conserver le wrapper Metro Uniwind (`withUniwindConfig` le plus à l’extérieur).

Le backend est NestJS dans `../api` ; ne pas créer de serveur concurrent dans les routes Expo.

Aucun chat n'est livré : si une issue en demande un, suivre le skill `assistant-ui-native`, qui indique les paquets à ajouter.
